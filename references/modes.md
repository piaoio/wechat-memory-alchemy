# 场景模式：同一批聊天记录，可以炼成十二种东西

原始聊天记录是"矿"，模式是"冶炼方案"。选错模式，库里会堆满没用的碎石。

**默认规则**：用户没说需求 → `M01 冷存档`（不加工、不丢失）。
**模式一旦选定 → 写进 `微信记忆库/_模式配置.md`**，同批次沿用，不要反复问。

---

## M01 冷存档 · Cold Archive

- **触发**：先存着 / 归档 / 备份一下 / 存到知识库
- **适用输入**：任何内容，尤其是没想好用途的
- **抽取**：只抽客观字段（人、时间、类型、原文），语义字段全部留空
- **输出**：一条记录 + 一篇原文文档
- **纪律**：**不总结、不评价、不删减**。用户没要分析就不要给分析。
- **落地**：`01_原始包/`

> 冷存档是所有模式的地基。任何模式下原文都必须还在。

---

## M02 思想资源 · Thought Vault

- **触发**：这是我的想法 / 记一下我的观点 / 攒灵感 / 我的思考
- **适用输入**：用户自己的长段表达、深夜感慨、争论中的立场
- **抽取**：把口语里的"主张"剥离出来，形成为命题
- **输出卡片**（每条想法一张）：

```markdown
### 命题：有些话说出口就已经变了意思
- 原文：「有些话说出口的瞬间就已经变了意思」（·阿禾，2026-03-14 23:07）
- 主张：语言在执行时会损耗原意，说出口即刻失真
- 依据：（原文未给，待补）
- 反例：（待补：是否存在"越说越清楚"的场合？）
- 关联：（待连到其他命题）
- 状态：未验证
```

- **落地**：`03_思维资源/`，一个主题一篇，命题多篇互链
- **价值**：三个月后你能看到"我当时的判断"，而不是一堆聊天记录
- **注意**：只收**用户自己的**观点。别人的话进 `M05 金句库` 或 `M04 人物观察`

---

## M03 生活日记 · Life Log

- **触发**：朋友圈 / 记录生活 / 做成日记 / 我这一年
- **适用输入**：朋友圈截图与文字、日常闲聊、随手拍
- **抽取**：事件（做了什么）+ 场景（在哪/和谁）+ 心情（情绪词）
- **输出**：按日/月的日记体，倒序

```markdown
## 2026-03-14 周六
> 有些话说出口的瞬间就已经变了意思

今天记下一句话，越琢磨越觉得对。
情绪：思考 · 场景：私聊 · 关键词：表达、失真
```

- **附加价值**：日记体不要只抄原文，可加一句"当时的天气/地点/在做什么"——用户补充，不要编造
- **落地**：`05_时间轴/2026-10.md`
- **注意**：朋友圈的发布时间必须保留，别用导出时间

---

## M04 人物观察 · People Watch

- **触发**：我关注的人 / 这个博主有意思 / 分析一下他 / 他总说
- **适用输入**：某人的多条发言、关注列表里的内容、群里的活跃者
- **抽取四件事**：

| 维度 | 抽什么 | 例 |
|---|---|---|
| 议题偏好 | 反复谈什么 | 教育、体制、亲密关系 |
| 表达特征 | 口头禅、句式、语气 | "本质上"、"说白了"、爱用反问 |
| 价值取向 | 赞成/反对什么 | 反效率崇拜、重个体感受 |
| 观点演变 | 前后是否变化 | 半年前支持，现在怀疑 |

- **输出**：`people/<昵称>.md`，一人一页，附**原话证据**（带日期）
- **纪律**：**只做文本观察，不做人格诊断**。写"他常谈 X"，不写"他是个 X 的人"。
- **注意**：这是分析他人言论，属敏感内容。只做用户主动提供的内容，不外传、不评价人品。

---

## M05 金句库 · Quote Bank

- **触发**：攒素材 / 好句子 / 文案用得上 / 这句真好
- **抽取**：可独立成立的表达（一句能脱离上下文被引用）
- **输出**：金句 + 出处（谁、何时）+ 适用场景标签（如：深夜、励志、反讽）

```markdown
> 有些话说出口就已经变了意思
— ·阿禾，2026-03-14
场景：随笔 / 转折句 · 情绪：克制
```

- **落地**：`03_思维资源/金句.md`，或数据表按"素材"主题筛
- **注意**：金句必须原样，一个字都不许改。改动即失真。

---

## M06 关系档案 · Relationship Map

- **触发**：和 X 的聊天 / 我们这些年 / 这段关系
- **适用输入**：与特定一人的跨时间对话
- **输出**：关系时间线 + 话题分布 + 承诺与兑现

| 日期 | 事件 | 我做了什么 | 对方做了什么 | 承诺 |
|---|---|---|---|---|
| 2026-10-29 | 深夜对话 | 倾听 | 表达犹豫 | — |

- **附加**：消息条数比、谁先开口、回复时延——客观关系指标
- **注意**：涉及第三方隐私，默认 `privacy_level: sensitive`，不外发

---

## M07 行动提取 · Action Extractor

- **触发**：有什么要做的 / 答应过什么 / 待办 / 别忘了
- **抽取**：谁 + 做什么 + 什么时候 + 状态
- **输出**：待办表（可直接进资料库数据表，`checkbox` 字段）

| 事项 | 责任人 | 截止 | 来源 | 状态 |
|---|---|---|---|---|
| 做分工表 | 小林 | 下周一 | 2026-10-29 09:20 | 未完成 |

- **规则**：只抽**明确约定**的（有动词、有时间或承诺语气）。"回头再说"不算。
- **落地**：数据表筛选 `行动项` 非空；或单开一张"待办"表

---

## M08 情绪轨迹 · Mood Track

- **触发**：我最近状态 / 情绪 / 是不是不太对
- **抽取**：情绪标签 + 时间 + 触发事件
- **输出**：时间序列（可画折线/热力），附"情绪—事件"对照
- **纪律**：只做描述统计，**不做心理诊断**，不给医疗建议。出现自伤等信号时，温和提示寻求专业帮助，不展开分析。
- **注意**：情绪词识别准确率有限，标 `confidence: low` 的条目不要进趋势结论

---

## M09 知识卡片 · Knowledge Cards

- **触发**：群里发的资料 / 干货 / 学一下 / 这个教程
- **抽取**：概念 + 要点 + 我的批注 + 出处
- **输出**（一卡一概念）：

```markdown
### 度分布的长尾
- 要点：多数节点度数极低，少数枢纽承担大部分连接
- 出处：群聊转发文章，2026-10-29
- 我的批注：解释为什么"平均转发数"没有意义
- 可迁移到：粉丝结构、漏洞影响面
```

- **落地**：`03_思维资源/知识卡片/`
- **注意**：批注与原文分开写，别把别人的观点当成自己的笔记

---

## M10 选题池 · Content Pipeline

- **触发**：做自媒体 / 找选题 / 这个能写一篇 / 素材
- **抽取**：素材片段 + 可延展的角度 + 目标读者 + 形式
- **输出**：选题表（选题 / 来源 / 角度假设 / 形式 / 优先级）
- **例**：一条"Three.js 做 3D 拆解页"的转发 → 选题「用代码造一个能拆的相机」→ 形式：图文+可交互 Demo
- **注意**：这是把别人的内容转成自己的产出，注明灵感来源，避免洗稿

---

## M11 家族记忆 · Family Archive

- **触发**：家里的老照片 / 长辈说的话 / 家族 / 口述
- **适用输入**：长辈语音（转文字）、老照片、家族群聊天
- **抽取**：人物 + 关系 + 时间 + 事件 + 原话（**保留方言与语气**）
- **输出**：人物谱系 + 口述史片段
- **纪律**：**不做文学加工**。老人说"那会儿饿"，就写"那会儿饿"，不要润色成"饥荒岁月"。
- **注意**：这是最不可再生的数据。语音原文件务必单独备份，转写文本标 `confidence: low` 的地方要标出来

---

## M12 决策复盘 · Decision Log

- **触发**：当时为什么这么定 / 复盘 / 上次那个决定
- **抽取**：背景 + 选项 + 理由 + 结果 + 回看
- **输出**：

```markdown
### 决策：分组按兴趣而非学号
- 时间：2026-10-28
- 背景：老师要求分组
- 选项：按兴趣 / 按学号
- 理由：学号分组太僵
- 结果：（待补，一个月后回看）
```

- **价值**：半年后回看"当时的信息"和"当时的判断"，能校准自己的决策习惯
- **注意**：结果字段留空比编造好，等真实结果发生再补

---

## 模式配置模板（`微信记忆库/_模式配置.md`）

```markdown
# 模式配置

- 主模式：M02 思想资源
- 辅助模式：M07 行动提取（只在出现明确约定时启用）
- 默认情绪识别：开
- 自动主题归类：开（关键词法，命中率约 60%，仅作初筛）
- 隐私默认等级：普通；涉及第三方对话 → 敏感

## 本库的特殊约定

- 只收我自己的表达，别人的话单独放 `04_人物档案/`
- 每条想法都要有"反例"字段，没有就写"待补"
```

**换模式的代价**：已入库数据不需要重算（原文都在），只需重新跑一遍派生层。这就是三层结构的意义。

---

## 怎么帮用户选模式（三句话问出来）

1. "你更想留着**原话**，还是想提炼**你的判断**？" → 原话=M01，判断=M02
2. "这些内容是你**自己写的**，还是**别人说的**？" → 自己=M02/M03，别人=M04/M05
3. "你希望以后**怎么用它**？翻着看 / 查资料 / 做内容 / 做决定？" → 分别对应 M03 / M09 / M10 / M12
